# Referencias de identidad corregidas

Primera revisión simplificada de las cartas del Boticario, descartada al revisar
los rasgos del personaje. Los originales y prompts quedan como procedencia.
La tanda activa usa objetos solos o una referencia propia de Mauro: hombre
con pelo oscuro y rostro descubierto, sin trenza. No se exporta esta carpeta.

# Generación de sprites

Herramienta: imagegen integrada, una generación por plantilla `enemigos1.png`
a `enemigos7.png` del directorio de conceptos del usuario. Se mantiene el orden
de ocho figuras de cada plantilla. Prompt compartido:

Use case: stylized-concept. Convert the EIGHT creatures in the supplied reference into a production game sprite atlas. Exact regular FOUR COLUMNS TWO ROWS, preserve order left to right top to bottom. One full creature per equal cell, all facing LEFT, preserve unique colors, equipment and silhouettes. Crisp dark fantasy pixel art suitable for 64x64 game sprites. Each creature centered inside its own cell with at least 15 percent clear margins on all four sides. Same baseline per row for grounded creatures. TRUE TRANSPARENT RGBA background, no scenery, no parchment, no text, no labels, no frames, no drop shadows, no grid lines. Eight individual isolated sprites only. Uniform evenly spaced layout filling canvas. Entire weapons, wings and tails visible.
